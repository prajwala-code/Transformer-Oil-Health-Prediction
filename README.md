# Transformer Oil Health Prediction using Random Forest

This project focuses on analyzing transformer oil performance based on chemical parameters using machine learning. A Random Forest algorithm was used to predict transformer oil health and support condition monitoring in electrical power systems.

## Objective

To study how transformer oil chemical parameters can be used to identify oil condition and support predictive maintenance decisions.

## Tools and Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Random Forest Algorithm

## Project Workflow

1. Collected or used transformer oil chemical parameter data
2. Preprocessed the dataset for machine learning
3. Trained a Random Forest model
4. Evaluated the model using a confusion matrix
5. Visualized parameter relationships using a correlation heat map

## Visualizations

### Confusion Matrix

The confusion matrix shows the classification performance of the Random Forest model for transformer oil health prediction.

### Correlation Heat Map

The heat map shows the relationship between different chemical parameters used for transformer oil condition analysis.

## Applications

- Transformer oil condition monitoring
- Predictive maintenance
- Fault indication support
- Power system asset management
- Data-driven maintenance planning
